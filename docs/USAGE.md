# GakuMotion 使用指南

本指南介绍如何在游戏内呼出 GakuMotion、导入并管理 MMD 动作/镜头资产，以及如何调节舞台表演与物理系统。

> 首次使用请确保已按照 [安装指南](INSTALLATION.md) 正确部署 GakuLoader 与插件依赖。

---

## 1. 打开控制面板

1. 启动游戏并进入**“偶像摄影”**模式（或由插件支持的更衣室摄影场景）。
2. 按快捷键 **Ctrl+M** 呼出或重新聚焦 GakuMotion 控制窗口。

> **场景准入说明**：
> - 为防止破坏游戏逻辑，插件仅在允许的摄影场景中激活；在游戏主页、常规 Live、P 培育流程中，面板将自动处于安全禁用状态。
> - GakuMotion 接管动作与运镜期间，游戏原生的手动拍照快门会被临时锁定。如需使用游戏原生拍照功能，点击面板底部的“停止”恢复原生状态即可。

---

## 2. 曲目与动作资产管理

在面板的**“曲库”**页面，你可以添加并统一管理舞蹈、表情、运镜与伴奏。

### 添加新曲目（4 步流程）
1. 点击 **“+ 添加到曲库”**，首选载入包含身体主干骨骼关键帧的 `.vmd` 动作文件。
2. 在弹出窗口中配置对应资源（若宿主环境支持，也可直接将多个文件批量拖入窗口）：
   - **身体动作**：必选，含身体关键帧的 `.vmd`。
   - **表情与视线**：可选，支持独立表情 `.vmd`；若不填，默认尝试提取身体 VMD 中自带的表情数据。
   - **运镜**：可选，支持镜头 `.vmd` 或已烘焙的 `.gkcamera` 文件。
   - **伴奏音频**：可选，标准 PCM 格式的 `.wav`；默认自动检索同名 WAV 或同目录下的 `song.wav`。
3. 输入易于识别的**曲目名称**，点击“添加”完成资产解析与导入。
4. 在曲库列表中选中该曲目，点击**“加载预览”**（进入第一帧定格检查），或点击**“播放选中”**立即开演。

导入器会识别特征明确的烘焙腿部动作，包括使用 `D` 腿骨、或普通腿骨逐帧动作配合逐帧空 IK 轨道的 VMD，并保留其腿部姿态。带显式 IK 开关、有运动的 IK 轨道以及无法明确识别的动作仍沿用原有处理。更新导入器不会自动修改已经导入的曲目；如需应用该修正，请重新导入原始 VMD。

### 曲目管理技巧
- **外部增删文件**：若直接在磁盘目录 `GakuLoader/PluginData/gakumotion/motions/` 下拷贝或删除了文件，点击面板的**“刷新曲库”**即可更新列表。
- **热更新当前曲目**：在外部修改了正在使用的动作或音频文件后，点击**“重新加载当前曲目”**，插件会在保留当前时间进度的情况下静止重载，方便实时比对修改。
- **删除曲目**：选中条目点击“删除选中”，二次确认后将**从磁盘永久删除**该曲目文件夹，请谨慎操作。

## 3. 播放控制与逐帧调试

屏幕底部的常驻播放条提供完整的走带与微调控制：

- **进度跳转**：拖动进度条，或在时间框中直接输入秒数 / `分:秒.毫秒`（如 `01:23.450`）后回车即可精确定位。
- **逐帧步进与定位**：
  - 支持直接输入动作帧号，或点击 **“上一帧” / “下一帧”** 按钮。
  - 步进操作会自动暂停播放，方便抓取特定瞬间排查骨骼穿模或截屏。
- **倍速与变速规则**：
  - 支持 0.1x 至 3.0x 多档播放速率。
  - ⚠️ **音频静音保护**：由于当前音频引擎采用时间戳硬同步，**当有效播放倍速不为 1.0 时音频会自动静音**，避免杂音撕裂；切回 1.0x 原速后声音会自动恢复。
- **停止复位**：点击“停止”按钮会立刻清空动作注入，将角色与相机控制权完整归还给游戏原生系统。
- **音乐音量**：播放栏可将 GakuMotion 音乐调至 0–100%，松开滑块后自动保存。它不调整游戏原声。若该文件只能由旧的 waveaudio 后端打开，界面会提示无法独立调整；播放继续保持原音量。有效播放倍速不为 1.0 时，音乐仍会按原规则静音。

## 4. 角色位置与运镜调节

### 角色位移调节
在**“动作”**页面，插件会自动识别当前场景中激活的偶像：
- 可微调角色的 X / Y / Z 世界坐标偏移量（单位：米）。
- 调整会即时反馈在画面上，切歌时自动保持；点击**“保存初始位置为默认”**后可记住当前站位。

### 表情幅度

在**“动作” → “表情幅度”**中可调整体、眉毛、眼部和嘴部倍率，范围为 0.00–2.00，默认均为 1.00。整体倍率与对应分项相乘；通常输出限制在 0–100%。已有超过 100% 的自定义基线不会在默认值下被截断，也不会被进一步放大。滑块影响当前播放的表情混合形状，包括角色默认表情；不改变眼骨视线或 LookAt。点击“重置表情幅度”恢复 1.00，点击“保存表情幅度”将设置写入 `Configs/gakumotion/facial_weights.json`，下次启动自动读取；未保存的调整只在当前运行期间保留。效果随角色和原动作而异。

### 镜头运转模式
在**“镜头”**页面或播放栏下拉菜单中，可自由切换以下运镜方式：

| 模式 | 运作表现 | 推荐使用场景 |
| :--- | :--- | :--- |
| **游戏** | 完全释放镜头接管，交还给游戏原生控制 | 需要手动用鼠标旋转构图、调整初始视角时 |
| **VMD** | 严格按照曲目绑定的运镜 VMD / GKCamera 轨迹播放 | 完整复刻原版 MMD 运镜分镜 |
| **跟随** | 摄像机位置与注视点同步跟随偶像移动 | 偶像有大幅位移或舞台走位时 |
| **注视** | 摄像机机位固定不动，镜头朝向自适应锁定偶像 | 模拟舞台固定机位特写拍摄 |

VMD 模式的 **“VMD 运镜范围”** 可将已加载镜头轨迹缩小到 0.30–1.00 倍，默认 1.00 保持原效果。轨迹以角色局部坐标中约 1 米高度为中心缩放，保留镜头朝向和视野，并同步缩放焦点距离及正交视野；现有位置偏移不受比例影响。此功能不检测场景碰撞，也不能保证构图或景深准确；建议从 0.80 开始尝试。点击“保存镜头设置”以保留设置。

> 💡 **跟随与注视调优**：
> - 跟踪锚点可在 **髋部 (Hips)**、**胸部 (Chest)** 或 **头部 (Head)** 之间切换（默认推荐髋部，动作最平稳）。
> - **追随速率**：`0` 为冻结、`0.1` 为电影感平滑阻尼、`1.0` 为硬性刚体锁定。

## 5. 舞台布景与物理系统

- **背景与绿幕控制**：在“舞台”页可开启纯色背景（支持自定义纯绿/纯白），配合截屏或 OBS 进行后期合成。
- **次级物理后端选择**（位于“设置”页）：
  - **实验性原生物理（推荐）**：优先调用学马仕原生 Unity 物理组件解算长发与裙摆，呈现原汁原味的动态摆动。
  - **内建物理（Fallback）**：当角色原生接口未识别时自动回退，通过内建弹簧骨骼保证最基础的布料摆动。
  - **关闭物理**：完全冻结次级物理，动作呈现绝对僵硬（仅用于性能排障）。

---

## 6. 常用快捷键一览

在游戏或插件窗口拥有焦点且未处于文本输入状态时，可使用以下快捷键：

| 快捷键 | 功能操作 |
| :--- | :--- |
| **Ctrl+M** | 呼出 / 隐藏 GakuMotion 控制面板 |
| **F9** | 播放 / 暂停 / 继续当前表演 |
| **F10** | 停止播放并复位原生状态 |
| **,** (逗号) / **.** (句号) | 切换至上一曲 / 下一曲 |
| **-** (减号) / **=** (等号) | 后退 5 秒 / 前进 5 秒 |
| **Shift+F11** | 从磁盘重新加载骨骼微调 |
| **Ctrl+F11** | 快速切换全局骨骼微调启用状态 |
